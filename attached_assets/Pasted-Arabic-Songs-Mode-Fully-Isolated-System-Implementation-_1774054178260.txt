Arabic Songs Mode — Fully Isolated System (Implementation Spec)

Objective

Build a completely isolated Arabic Songs Mode inside the bot.
This mode must:
	•	NOT interfere with any existing logic, commands, NLP, or workflows
	•	NOT modify any current handlers or services
	•	Operate as an independent pipeline with its own routing, parsing, and resolution
	•	Fail safely without impacting the main system

⸻

🔒 1. Isolation Rules (CRITICAL)
	1.	This feature MUST be implemented as a separate module / handler layer
	2.	No modification to:
	•	Existing /song, /lyrics, /analyze, /recommend, etc.
	•	NLP router
	•	Existing services or scoring logic
	3.	Use a user-scoped state flag only:

user_mode[user_id] = "arabic"

	4.	Routing rule (top priority in message handler):

if user_mode == "arabic":
    route_to_arabic_mode_handler()
    return

	5.	If Arabic mode fails at any point:

	•	Return a controlled message
	•	DO NOT fallback into main bot logic

⸻

🎯 2. Commands

دخول الوضع:

/arabic

Response:

🎵 Arabic Mode Activated

Please use:
Artist - Song

Example:
ماجد المهندس - ضايع

Type /exit to return


⸻

الخروج:

/exit

Response:

Exited Arabic Mode

	•	Clears user_mode
	•	Restores normal bot behavior

⸻

🧠 3. Input Rules داخل Arabic Mode

Strict format only:

artist - song

Reject:
	•	Missing “-”
	•	Multiple “-”
	•	Empty artist/song

Error message:

Please use the correct format:
Artist - Song

Example:
ماجد المهندس - ضايع


⸻

🔤 4. Arabic Normalization Layer (MANDATORY)

Apply BEFORE any search.

Normalize into a separate key (do NOT overwrite original text)

Rules:
	1.	Remove diacritics ( َ ً ُ ٌ ِ ٍ ْ ّ )
	2.	Normalize:
	•	أ إ آ ٱ → ا
	3.	Normalize:
	•	ى → ي
	4.	Normalize:
	•	ؤ → و
	•	ئ → ي
	•	ء → remove (soft handling)
	5.	Remove tatweel:
	•	ـ
	6.	Normalize spaces
	7.	Normalize dash:
	•	– — → -

Example:

فؤاد عبدالواحد → فواد عبدالواحد
أبي منك → ابي منك


⸻

🔍 5. Resolver Pipeline (Multi-Layer)

Run layers in parallel where possible.

⸻

Layer 1 — Arabic Exact Search (Primary)

Query:

artist + song (original)

Source:
	•	YouTube Music (search)

Goal:
	•	Extract clean:
	•	artist
	•	song

⸻

Layer 2 — Arabic Normalized Search

Query:

normalized_artist + normalized_song


⸻

Layer 3 — Secondary Source (Metadata/Lyrics)
	•	Try lyrics source directly (LRCLIB or equivalent)
	•	Try metadata resolver if available

⸻

Layer 4 — Romanized Fallback (LAST)

Generate limited variants:

عايض → ayed
بالموت → bel moot

DO NOT over-generate

⸻

🧪 6. Candidate Collection

Each layer returns candidates:

{
  artist,
  song,
  source,
  raw_title,
  confidence_score (to compute)
}


⸻

🧠 7. Ranking System (CRITICAL)

DO NOT use first result.

Score each candidate:
	•	Artist match: 50%
	•	Song match: 40%
	•	Clean title: 10%

⸻

❌ Hard Filters:

Reject if title contains:
	•	remix
	•	live
	•	cover
	•	slowed
	•	sped up
	•	karaoke

⸻

Winner Rule:
	•	Select ONLY if:
	•	clearly أعلى من غيره
	•	exceeds threshold

⸻

If ambiguous:

🎵 Multiple matches found.
Please refine your input using:
Artist - Song


⸻

Once winner selected:

artist + song → lyrics API

If lyrics found:
→ continue

Please try another track.

	•	DO NOT call other commands
	•	DO NOT trigger NLP

Return controlled message only

🔁 12. State Safety
	•	Mode applies per user only
	•	Must NOT leak between users
	•	Must NOT persist incorrectly

⸻

🚫 13. Strict Constraints
	•	NO changes to existing system
	•	NO shared logic mutation
	•	NO performance regression
	•	NO API overuse
	•	NO global side effects
