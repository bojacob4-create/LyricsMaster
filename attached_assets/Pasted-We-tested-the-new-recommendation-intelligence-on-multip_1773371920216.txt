Findings from testing

1) Sam Smith - Too Good At Goodbyes

The result was partially reasonable, but still included off-target candidates such as:
	•	Whiskey Myers
	•	some weak emotional-male matches

This suggests the system is still over-weighting broad emotional tags and under-weighting actual style fit.

2) Billie Eilish - Happier Than Ever

Results were too generic and not close enough to Billie’s actual alt-pop / emotional dramatic style.

The system appears to detect “emotional female pop” but not the more specific vibe family.

3) Dua Lipa - Levitating

This was a clear miss.

The output included artists like:
	•	Luke Combs
	•	Ella Langley

This means the current logic is treating the song as only “upbeat pop,” which is too broad.

Levitating needs recommendations closer to:
	•	dance-pop
	•	disco-pop
	•	synth-pop
	•	club-friendly upbeat energy

4) Burna Boy - Last Last

This was also a miss.

The results leaned too much toward:
	•	generic male energetic tracks
	•	hip-hop / rap artists like Future / Drake

instead of true Afrobeats / Afro-fusion matches.

This means the current system is under-weighting regional genre identity.
