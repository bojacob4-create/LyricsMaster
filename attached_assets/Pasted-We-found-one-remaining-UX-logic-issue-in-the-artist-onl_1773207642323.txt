Remaining Problem 1 — “Song Dashboard” does not work well for artists outside the static artist database

Example:
	•	analyze kehlani

The bot correctly identifies Kehlani as an artist and shows the artist interface.

But when pressing:
	•	Song Dashboard

the bot falls into an ambiguity message like:
	•	I'm not sure if "Kehlani" is a song or an artist.

This means the Song Dashboard button in the artist-only analyze interface is still relying on logic that does not work generally for artists outside the static artist database.

Required behavior

In the artist-only analyze interface, the Song Dashboard button should NOT directly call a single ambiguous /song ArtistName flow.

Instead, it should behave like an artist song picker:
	•	show top / known songs for that artist
	•	then let the user choose one
	•	then open /song Artist - Song

This should work for:
	•	artists in the static database
	•	artists resolved via Wikipedia fallback
	•	artists detected through artist-only analyze logic

Do NOT hardcode only Kehlani or Selena Gomez.
This must work generally.
