UPGRADE 1 — GLOBAL TRANSLATION
==================================================

Current behavior:
The bot translates lyrics to Arabic only.

Goal:
Allow the user to choose the target language in a clean and easy way, both through the /translate command and through natural-language input.

Requirements:

1. Keep the current /translate command working.
2. Extend it so users can specify the target language naturally.

Supported examples should include:
- /translate hello adele to spanish
- /translate blinding lights to french
- /translate counting stars to arabic
- /translate someone like you to turkish

Natural-language examples that should work:
- translate hello by adele to spanish
- can you translate blinding lights to french
- translate counting stars into arabic
- i want someone like you translated to italian

3. If the user does NOT specify a target language, keep the current default behavior exactly as it is now.
   In other words:
   - /translate hello adele
   should still work the same way it currently works.

4. The target-language syntax should be simple and forgiving:
   - “to spanish”
   - “into spanish”
   - “in spanish”
   should all be understood.

5. The output should clearly show the selected target language.
   Example:
   Adele - Hello
   Translation: Spanish

6. If the requested language is unsupported or invalid, return a clean friendly error message and suggest supported examples.

7. Do not make the translation flow hard or complicated.
   Keep it easy for normal users.

Important scope rule:
Only touch the code necessary for translation command parsing, natural-language translation parsing, and the translation handler/service.
Do NOT alter unrelated commands.

Important:
